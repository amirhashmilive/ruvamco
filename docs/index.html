GitHub Repository Quick Start
MIT License • Open Source • Production Ready
ruvamco-config.yaml 
apiVersion: ruvamco/v1
kind: EdgeRoute
metadata:
  name: my-api-route
spec:
  domain: api.mycompany.com
  backend:
    type: kubernetes
    target: my-service.default.svc.cluster.local
    port: 8080
  rateLimit:
    requestsPerSecond: 1000
    burst: 2000
  auth:
    type: jwt
    jwksUrl: https://auth.internal/.well-known/jwks.json
$ ruvamco apply 
✓ Provisioning started (op_abc123)
✓ Service ready at https://api.mycompany.com
Duration: 24.3s

📦 Quick Start

1

Clone & Install

cd ruvamco
make setup
2

Start Services

make up
# Wait for health checks (30s)
3

Deploy Your Route

ruvamco apply examples/basic-config.yaml --wait
